- **fix(compression):** live-zone prefix reuse no longer sends an empty messages list when every turn is already frozen. `reuseLiveZoneEntry` returned the body unchanged only when live items existed; when all messages were frozen (`liveItems.length === 0`) it fell through to `compress()`, which rebuilt the body with `messages: []` — sending zero messages to `codex/gpt-6.1-sol` and triggering OpenAI's "Potentially unintended activity" safety block. Now the frozen prefix is restored verbatim, the compressor is not invoked again, and `compressed: false` is set. Covered by a regression test in `tests/unit/compression/live-zone.test.ts`.
